minecraft assets api

Esta é uma API simples para recursos do Minecraft. Não é uma API completa, mas sim uma API simples para recursos do Minecraft.

Esta API contém 1.141 texturas de blocos e 740 texturas de itens, todas com os mesmos nomes do Minecraft.

Como usar

  • /minecraft-assets-api/img/block/stone.png - Retorna a imagem para um bloco específico.
  • /minecraft-assets-api/img/itens/wood_pickaxe.png - Retorna a imagem para um item específico.

Para deixar a imagem com uma boa qualidade, utilize a propriedade

image-rendering: pixelated;

no CSS.
